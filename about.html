About us

More than a store, Anime Haven is a fan community.

Founded in 2026, Anime Haven was created to make authentic anime merchandise easier to find for South African fans.

Our story

Built by fans, designed for collectors.

Anime Haven began with a simple observation: South African anime fans often had to search across multiple marketplaces to find genuine figurines, manga volumes and posters. The website brings those products into one readable, mobile-friendly catalogue with clear pricing, product categories and enquiry options.

Every page uses semantic HTML5 structure, accessible navigation, descriptive image text and responsive design so visitors can browse comfortably on phones, tablets and desktop screens.

Values

What guides our service.

Authenticity

Product information clearly explains category, condition and availability before customers make an enquiry.

Accessibility

Pages use keyboard-friendly navigation, meaningful labels, visible focus states and responsive layouts.

Community

The store supports local fan culture through genre browsing, new arrival updates and helpful support.

Timeline

Project development path.

  1. Planning: research target users, product categories and competitor stores.
  2. Foundation: build semantic HTML pages, navigation and GitHub documentation.
  3. Styling: apply mobile-first responsive CSS and test across breakpoints.
  4. Functionality: add search, gallery, tabs, accordions, map and form validation.
  5. Deployment: publish the site, test live links and submit evidence.
