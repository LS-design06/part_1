# Proposal 2: Umthombo Community Garden (Non-Profit)

## Current Analysis

Umthombo Community Garden is a non-profit initiative addressing food security in urban South African communities. Currently, residents lack access to fresh produce and green spaces for community engagement. The garden provides plots for growing vegetables, educational workshops, and volunteer opportunities.

## Proposed Features

- Informational website with mission and values
- Volunteer sign-up form
- Event calendar and workshop listings
- Photo gallery of garden activities
- Contact form for donations and partnerships
- Map with garden location and directions

## Design Aesthetic

Earth-toned color palette with natural greens and browns. Clean, accessible design prioritizing readability and easy navigation. Layout emphasizes community photos and testimonials.

## Tech Stack

- HTML5 semantic structure
- CSS3 responsive design with Flexbox
- Vanilla JavaScript for form validation
- Leaflet.js for location map
- GitHub Pages for hosting

## Timeline

- Week 1-2: Community engagement and requirements gathering
- Week 3-4: Structure and content development
- Week 5-6: Styling with responsive design
- Week 7-8: JavaScript features and forms
- Week 9: Testing and launch
- Week 10: Handover and documentation
