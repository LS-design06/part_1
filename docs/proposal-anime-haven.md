# Proposal 1: Anime Haven Retail Store

## Current Analysis

Anime Haven addresses the gap in South Africa's anime merchandise market. Currently, fans must navigate multiple international retailers with long shipping times, high import costs, or rely on local platforms with limited authentic product selections. The business will operate as an online-first retail store focusing on three core categories: figurines, manga volumes, and collector posters.

## Proposed Features

- Responsive product catalogue with search and category filtering
- Product enquiry system with quote generation
- Interactive gallery showcasing merchandise
- Contact form for customer support
- Mobile navigation with hamburger menu
- Interactive map showing service region

## Design Aesthetic

Dark theme with red accents (#c0162a) reflecting anime energy. Typography uses Arial/Helvetica for readability with Georgia serif for headings. Layout features modern card-based design with subtle animations on hover.

## Tech Stack

- HTML5 with semantic structure
- CSS3 with Flexbox/Grid and custom properties
- Vanilla JavaScript for interactivity
- Leaflet.js for interactive map
- Netlify for deployment
